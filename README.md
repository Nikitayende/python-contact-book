# Contact Book

A simple Python-based Contact Book application that allows users to store, view, and search contact information through a menu-driven interface.

## Features

- Add New Contacts
- View All Contacts
- Search Contacts by Name
- User-Friendly Menu System
- Exit Application

## Concepts Used

- Python Variables
- Lists
- Dictionaries
- While Loop
- For Loop
- If-Elif-Else Statements
- String Handling
- User Input

## How It Works

1. Add a contact by entering a name and phone number.
2. View all saved contacts.
3. Search for a contact using the contact name.
4. Exit the application.

1. Add Contact
